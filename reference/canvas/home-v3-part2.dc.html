Questions

Before you book a call

01What does the free audit need from us?

Your Figma file. Read access to the repo is optional; with it, we also compare your Figma tokens against the compiled CSS and source code.

02Do we need to rename everything first?

No. Renaming is risky and IDs are cheap. Each token gets an ID that survives renames, a scope and a code name, and Figma stays the source of truth.

03What does “AI-ready” actually mean?

Four checks you can run today: components have descriptions, components bind to semantic tokens rather than primitives, inputs declare their icon and action slots, and tokens have descriptions.

04We have a live product with legacy code. Can you still help?

That is most of our work. We migrate in slices, so the product keeps shipping while the system replaces what was there.

05Won’t this slow our team down?

We start with one real surface from your roadmap as the pilot, so the first thing the system produces is something you were going to ship anyway.

06How does this work with our coding agents?

Every token and component gets a context file your agents read. The pilot can be built by your team’s agent, and it has to pass the same defect gate.

07Who maintains the system after you leave?

Your team, with the documentation and review cadence we set up. Or we stay on as your systems partner on a monthly retainer.
